# 架构与实现取舍

## 1. 部署模型

Vue3 构建产物由 Spring Boot 同源提供，减少本机启动步骤。Compose 在前方增加 Nginx，数据存储切换为 MySQL。本机 H2 文件模式无需额外安装数据库，属于为当前环境增加的演示能力。

后台任务在应用内 2 个线程中执行，持久化内容包含批次 manifest、每个 case、每次尝试、评分历史、步骤和审计。单实例下所有领取、取消、完成和评分修订通过同一应用监视器串行协调；批次及任务创建、领取计数使用数据库事务。

原 TRD 的数据库条件更新、多实例 lease 竞争尚未实现。该版本明确只允许单应用实例，不提供分布式 Worker 的正确性承诺。

## 2. 存储变更 ADR-001

原计划为 MyBatis-Plus + 规范化实体表。首轮使用 Spring JDBC 与 `documents` 快照表，字段为 id、kind、project_id、body、created_at；JSON body 保存各领域实体，schema_history 记录初始化版本。

理由：先验证跨页面的业务闭环以及不可变版本/报告语义，同时兼容本机 H2 和 MySQL。代价：列表和聚合在应用层进行，单次返回当前项目全部数据，不适用于大规模 trace 或企业生产数据。后续应拆分标准实体表、索引与分页，再开展性能验收。

状态字段允许更新，已发布数据集、Agent 配置和报告没有覆盖修改 API。评分改判追加原评分到 score_history，并以 supersedes_id 关联。hash 用于内容一致性，不声明数据库管理员不能篡改。

## 3. 状态与恢复

- 批次：QUEUED → RUNNING → COMPLETED / COMPLETED_WITH_ERRORS / CANCELLED。
- case：PENDING → RUNNING → SUCCEEDED / CALL_ERROR / NEEDS_REVIEW / CANCELLED。
- score：PENDING / SCORED / UNKNOWN / ERROR；SCORED 的 passed 为布尔值。
- 执行时先持久化 lease_token、lease_until、attempt、请求计数，再调用外部接口。
- 只有当前 lease 对应的完成结果可提交。
- 超时加 15 秒后租约过期。重启时已完成结果直接保留，过期的 RUNNING 尝试标记 INTERRUPTED；明确幂等且仍有重试/请求预算时重新排队，否则 NEEDS_REVIEW。
- 中断请求的费用可能未知，不补零；平台不保证外部工具恰好执行一次。
- 取消停止新请求领取，已经在途的请求按完成或超时收尾。
- 重试仅针对临时连接问题、429、5xx，必须接口幂等或 mock，最多额外一次；默认不重试。

## 4. 评测与对比

通过率=P/(P+F)，覆盖率=(P+F)/计划 case，总样本通过占比=P/计划 case。分母为零返回 null。技术错误单列，不能靠排除异常夸大覆盖率。

比较时要求同项目、同 dataset hash、同 evaluator_version 和两个终态批次。双方均 SCORED 的 case 才纳入配对分母；人工复核是此评分版本的可追溯修订，报告记录导出时所有评分 ID。

延迟统计按每次成功请求的单调时钟总耗时计算 nearest-rank P50/P95；错误请求另有 error_p95_ms。重试尝试单独保留。已知成本为所有可计价尝试之和，价格单位元/百万 Token，显示成本覆盖率。模拟价格不等于实际供应商报价。

缺少完整工具 trace 时工具判定 UNKNOWN；若已有可确定的文本规则失败，则可直接判失败并给出理由。不采集隐藏思维链。模型 judge 未启用。

## 5. 数据和接口约束

账号是固定预置的四个演示身份，项目成员映射决定实际权限。HTTP Basic 凭据仅在前端内存持有，不使用 cookies 或 localStorage。生产化需要独立实现身份管理、密码策略、限流和 HTTPS。

企业端点采用服务器配置的精确 origin 允许列表，初版只允许固定 IPv4，禁止重定向及链路本地元数据地址，以避免直接信任任意 URL 或 DNS 解析变化。内部网络地址仅可由部署人员显式允许。密钥只允许引用 AGENT_SECRET_ 前缀的环境变量，界面和报告不接收真实密钥文本。

脱敏报告采用严格隐藏模式：全部问题、回答、理由、引用及业务 case_id 隐藏，仅保留匿名编号、状态和统计；避免把简单正则替换误认为可靠脱敏。内部完整模式保留这些内容，对文本做 HTML 转义；两个模式均不嵌入脚本或远程资源。
