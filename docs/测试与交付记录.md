## 关键验证覆盖

JUnit 包含：质量/覆盖率及成本缺失分母、完整 trace 工具规则、canonical hash、A/B 配对、人工复核权限与历史、报告快照不随改判改变、项目隔离、导入行级错误、发布不可变、端点允许列表、请求预算、取消标记持久化、trace 重复/冲突/缺父节点。8 个测试方法覆盖上述多个断言。

Playwright 包含：登录 → 新建 A/B → 等待执行 → 配对比较 → 退化案例与详情 → 脱敏报告预览与下载 → 桌面/手机截图；另验证评审者不显示运行入口、隔离账号仅访问其自身项目。页面运行时未捕获 JavaScript 异常。

中断测试使用独立 8082 端口和独立测试数据库，不修改演示库。实际终止 JVM 后重启；本地 H2 配置 WRITE_DELAY=0，使提交同步落盘。测试禁用自动重试，故不确定的中断请求进入待核对状态，不伪造外部执行结论。

## 未验证或尚未实现

- 当前机器无 Docker/MySQL：Compose、Nginx 和 MySQL 兼容部署配置已提供，但容器启动、MySQL 持久化/恢复未实测。
- 未完成真实企业 HTTP 接入、业务人员签认可用性、真实数据授权、企业复测及收益测量。
- 未执行 10 万 trace / 10 并发 / P95≤2秒目标；当前文档快照存储和无分页列表不适合该规模。
- 原 TRD 的多实例数据库条件领取、标准领域关系表、独立 Worker 尚未实现；当前限定单 JVM、两个执行槽。
- 节点 SDK、模型裁判与一致率校准、定时回归、生产告警未实现。
- 暂未制作配音的 3–5 分钟路演视频；提供实际页面截图和可复现的演示脚本。
- 学校正式申报书、PPT、团队成员资料、企业访谈与合作证据需使用真实信息继续完成。

## 复现命令

```powershell
# 构建前先停止正在使用同一个 target JAR 的 Java 进程
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1

# 主系统启动后，在另一个终端运行浏览器测试（需要本机 Edge）
cd frontend
npm run test:e2e

# 在项目根目录执行独立恢复与 mock 性能验证
node scripts/verify-recovery.mjs
```

浏览器测试会在演示项目创建新批次和报告，不清空历史；恢复测试使用 .tools 下独立目录。测试生成的截图与示例报告仅含自建模拟样本。
